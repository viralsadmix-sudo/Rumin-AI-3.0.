🖥️ PC Connect · Local Network

Windows 10 PC ও ফোন একই private Wi-Fi-তে রাখুন। PC Companion চালু করে PC-র IPv4 address দিন। এই পরীক্ষা শুধু PC-র health status পড়ে; কোনো PC control command বা pairing token পাঠায় না।

এখনো PC পরীক্ষা করা হয়নি।

Pairing একই Private Wi-Fi-তে করুন। বর্তমান Companion HTTP ব্যবহার করে; তাই Pairing Token পাঠানোর সময় নেটওয়ার্ক এনক্রিপশন নেই। Token ফোনে Android Keystore দিয়ে এনক্রিপ্ট করে রাখা হবে। HTTPS secure relay তৈরি না হওয়া পর্যন্ত PC-তে Remote Control চালু হবে না।

Multi-AI Router: Gemini → Groq → Grok → ChatGPT → Muse Spark (যে Key সংরক্ষিত আছে, সেটিই ব্যবহার হবে)। Gemini Live Voice আলাদা থাকবে।

ElevenLabs শুধু সাধারণ Voice Chat-এর উত্তর বলবে। Gemini Live Voice অপরিবর্তিত থাকবে। নিরাপত্তার জন্য ElevenLabs API Key অ্যাপে দেবেন না; HTTPS Backend-এ রাখুন। Backend-এর Secret হিসেবে ELEVENLABS_API_KEY ও RUMIN_PROXY_TOKEN সেট করুন। অ্যাপের Token ও Backend Secret একই হবে। POST /v1/tts রুট JSON {"text":"...","voice_id":"...","model_id":"..."} নেবে এবং audio/mpeg ফেরত দেবে। Proxy না থাকলে ফোনের নিজস্ব TTS ব্যবহার হবে।

নোট: API Key এই ডিভাইসের অ্যাপ স্টোরেজে রাখা হবে। নিরাপদ সার্ভার-ভিত্তিক Key Vault এখনো সংযুক্ত নয়। API ব্যবহারে খরচ হতে পারে।

ফোন কন্ট্রোলের জন্য: Accessibility সেবা চালু রাখুন। Android 13+ এ সাইডলোড করা অ্যাপে App info → ⋮ → “Allow restricted settings” দিতে হতে পারে।
