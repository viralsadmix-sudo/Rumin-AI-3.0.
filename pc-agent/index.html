Rumin PC Agent — আপনার Windows কাজের জন্য একটি আধুনিক AI control workspace। Companion সংযুক্ত হলে অনুমোদিত ফাইল, অ্যাপ, স্ক্রিন ও প্রিন্টিং কার্যক্রম এখান থেকে পরিচালনা করা যাবে। Android থেকে নিরাপদ remote control এখনো সংযুক্তির অপেক্ষায়।

Safety Center · অনুমতি ও নিশ্চিতকরণ
Rumin PC Agent-এ প্রতিটি capability আলাদা করে বন্ধ রাখা হয়। সংবেদনশীল কাজ চালানোর আগে Windows user-এর অনুমতি, চলমান local desktop session এবং action confirmation প্রয়োজন হতে পারে।
নিরাপত্তার নিয়ম
  • সব PC permission ডিফল্টে বন্ধ থাকবে; প্রয়োজনীয় permission শুধু PC Permissions থেকে চালু করুন।
  • Screen capture ও mouse/keyboard control কেবল এই PC-তে user-started local session-এ চলবে।
  • ফাইলের কাজ শুধু অনুমোদিত Documents/Pictures root-এ সীমাবদ্ধ; delete করলে Recycle Bin-এ যাবে।
  • Print job, file overwrite/move/delete এবং Agent plan চালানোর আগে আলাদা confirmation দেখানো হবে।
  • Pairing code একবার ব্যবহারযোগ্য ও স্বল্পমেয়াদি; secure Android-to-PC relay সম্পূর্ণ না হওয়া পর্যন্ত remote command চালু নয়।
  • UAC secure desktop, password field এবং Windows protected surface bypass করা হবে না।
