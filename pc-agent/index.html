PC Permissions & Safety

প্রতিটি অনুমতি আলাদা। সব অনুমতি ডিফল্টে বন্ধ থাকবে; Windows ব্যবহারকারী নিজে চালু করবেন।

৩. এখনো তৈরি হয়নি

Printer control, file create/edit/move/delete, OCR, Windows UI Automation, microphone/camera stream এবং secure phone-to-PC relay এখনো বাস্তবায়িত নয়—এগুলোর কোনো permission toggle এখানে কার্যকর বলে দেখানো হবে না।

Windows Firewall জিজ্ঞেস করলে Private networks-এ অনুমতি দিন; Public networks-এ নয়। UAC/Secure Desktop বা Windows-এর নিরাপত্তা সীমা অতিক্রম করা হবে না। যেকোনো সময় screen session বন্ধ করতে পারবেন।

Rumin Agent Control

এটি Companion-এর অনুমোদিত local action executor। কাজের ধাপ যোগ করে একসঙ্গে চালাতে পারবেন। AI natural-language planner ও phone relay এখনো সংযুক্ত নয়।

Execution plan

  1. কোনো action যোগ করা হয়নি।
Execution এখনো শুরু হয়নি।

একটি batch-এ সর্বোচ্চ ৮টি action। PC-তে Companion চালু, প্রয়োজনীয় permission ON এবং screen action-এর জন্য local desktop session চালু থাকতে হবে। Delete, payment, message send, admin/security পরিবর্তন বা arbitrary shell command এই executor চালায় না।
